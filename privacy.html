Privacy Policy

Hermes Agent — personal automation assistant. Last updated: 27 September 2026.

This policy describes how Hermes Agent (the "application") handles information obtained through Google APIs. The application is a private, single-user tool operated by its owner on the owner's own server. It is not offered to the public and has no users other than its owner.

1. Information accessed

With the owner's explicit consent, the application may access the owner's own Google account data:

  • Gmail — messages, to build the owner's daily briefing and search the owner's own mail on request.
  • Google Calendar — events, to report the owner's schedule and detect conflicts.
  • Google Drive, Docs and Sheets — files owned by the owner, to read, create and update documents on request.
  • Contacts — read-only, to resolve names that appear in the owner's own mail and calendar.

2. How the information is used

Information is used solely to carry out the tasks the owner asks for. It is processed automatically and presented back to the owner in the owner's own chat interface. No profiling, advertising, marketing or analytics use is made of it.

3. Storage

Access tokens are stored on the owner's private server. Retrieved content is held only as long as needed to answer the owner's request. The application does not operate a central database of Google user data, because it has no other users.

4. Sharing and disclosure

Data is not sold, rented or shared with third parties. Data is not transferred to any party other than the model providers that the owner has configured to process the owner's own requests. Such transfers are limited to what is necessary to answer the request. Google user data is never used to train machine-learning models.

5. Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

The owner may revoke the application's access at any time at myaccount.google.com/permissions. Doing so immediately invalidates the stored token and the application can no longer read any Google data. Locally cached content can be deleted by the owner at any time.

7. Security

Tokens are stored with filesystem permissions restricted to the owner's server account, and all traffic to Google APIs uses TLS.

Any change to this policy will be published on this page.
