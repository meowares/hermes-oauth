Hermes Agent

Personal automation assistant — single-user deployment

Hermes Agent is a private, self-hosted automation assistant operated by and for a single individual (the account owner). It helps its owner organise daily work: summarising email, tracking calendar commitments, and preparing research notes.

What it does

  • Reads and searches the owner's own mailbox to produce a daily briefing.
  • Reads the owner's own calendar to flag scheduling conflicts.
  • Reads and writes documents in the owner's own drive on request.

Who can use it

The application is not offered to the public. There is no sign-up, no user base, and no third-party access. It is installed on the owner's own server and only ever authorises the owner's own Google account.
